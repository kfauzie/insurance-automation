# Insurance automation

Prototypes of internal AI tools for claims handlers at Fernway, an AI-native claims administrator. **Fernway is a made-up name, and all data is synthetic.**

Built with the [product workflow](https://github.com/kfauzie/product-workflow) skills in `.claude/commands/`: data review, discovery, spec, design, prototype, MVP review. Context lives in `context/`; each problem gets its own folder in `runs/`.
